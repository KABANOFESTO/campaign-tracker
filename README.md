This is the backend of the campaign management system. It provides the necessary API endpoints for managing campaigns, including creating, updating, and fetching campaign details.

## Technologies Used

- **NestJS**: A progressive Node.js framework for building efficient, reliable, and scalable server-side applications.
- **TypeScript**: A superset of JavaScript that compiles to plain JavaScript.
- **MongoDB**: NoSQL database for storing campaign data.
- **Mongoose**: ODM (Object Data Modeling) library for MongoDB.
- **dotenv**: Environment variable configuration.
